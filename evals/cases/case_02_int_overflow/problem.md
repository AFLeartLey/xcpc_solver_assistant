# 数组求和（64 位范围）

## 题目描述

给定 `n` 个整数，求它们的总和。

## 输入格式

- 第一行一个整数 `n (1 <= n <= 2 * 10^5)`。
- 第二行 `n` 个整数 `a_i (-10^9 <= a_i <= 10^9)`。

## 输出格式

输出一个整数，表示所有元素之和。

## 样例输入

```text
5
1 2 3 4 5
```

## 样例输出

```text
15
```

## 数据范围

- `1 <= n <= 2 * 10^5`
- `-10^9 <= a_i <= 10^9`
- 答案最大可达 `2 * 10^14`，**请使用 64 位整数**。
