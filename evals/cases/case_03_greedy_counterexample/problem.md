# 0/1 背包（小数据）

## 题目描述

有 `n` 件物品，第 `i` 件物品重量为 `w_i`，价值为 `v_i`，背包容量为 `W`。
每件物品最多只能取一次。求在总重量不超过 `W` 的前提下能获得的最大总价值。

## 输入格式

- 第一行两个整数 `n, W (1 <= n <= 6, 1 <= W <= 20)`。
- 接下来 `n` 行，每行两个整数 `w_i, v_i (1 <= w_i <= 20, 1 <= v_i <= 20)`。

## 输出格式

输出一个整数，表示最大总价值。

## 样例输入

```text
2 10
6 12
4 8
```

## 样例输出

```text
20
```

## 数据范围

`n <= 6`，`W <= 20`，物品不可分割（0/1 背包）。
