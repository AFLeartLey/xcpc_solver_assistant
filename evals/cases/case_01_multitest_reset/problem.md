# 子树权值和（多组数据）

## 题目描述

给定 `T` 棵**以 1 号节点为根**的树。每棵树有 `n` 个节点，第 `i` 个节点有一个整数权值 `a_i`。
对每棵树，求出**每个节点子树（含自身）的权值之和**。

## 输入格式

- 第一行一个整数 `T (1 <= T <= 5)`，表示数据组数。
- 对于每组数据：
  - 第一行一个整数 `n (1 <= n <= 8)`。
  - 第二行 `n` 个整数 `a_1 ... a_n (-10 <= a_i <= 10)`。
  - 接下来 `n - 1` 行，每行两个整数 `u v (1 <= u, v <= n)`，表示一条树边。

## 输出格式

对于每组数据，输出一行 `n` 个整数，第 `i` 个数表示节点 `i` 的子树权值和。

## 样例输入

```text
1
4
1 2 3 4
1 2
1 3
3 4
```

## 样例输出

```text
14 2 7 4
```

## 数据范围

`T <= 5`，`n <= 8`，答案绝对值不超过 `10^4`。
